○ What is the difference between React, React JS, and React Native? 
React and ReactJS both refer to the JavaScript library intended for constructing user interfaces, mostly in the context of web development. 
React Native is an entirely separate framework designed for creating cross-mobile platform mobile applications.
○ Is React a framework or library? What is the difference? 
React is a library rather than a framework. React’s library allows for developers to create dynamic and interactive user interfaces mostly for web applications. 
A library is a collection of reusable code that you can import and use when you need it. A library allows for full control over when and how it is used.
A framework is what provides a comprehensive structure for building applications. A framework will influence a complete structure for the application. Components like guiltiness as far as organizing code, handling data flow, and managing different parts of the app like (M-V-C).
